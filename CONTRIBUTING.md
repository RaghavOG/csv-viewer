# Contributing to PlaneCSV

Thank you for your interest in contributing!

## Development Setup

1. Fork and clone the repository:
   ```bash
   git clone https://github.com/RaghavOG/csv-viewer.git
   cd csv-viewer
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the local dev server:
   ```bash
   npm run dev
   ```

4. Verify build and types before submitting a pull request:
   ```bash
   npm run build
   ```

## Pull Request Guidelines

- Keep changes focused and well-documented.
- Maintain responsive behavior and dark/light mode compatibility.
- Ensure all TypeScript types pass check.
