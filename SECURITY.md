# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of PlaneCSV seriously. If you discover a security vulnerability, please report it responsibly:

1. **Do not** report security vulnerabilities through public GitHub issues.
2. Please report security vulnerabilities privately via GitHub Security Advisories or by reaching out to the maintainer via GitHub ([@RaghavOG](https://github.com/RaghavOG)).
3. Please include details about:
   - Type of issue (e.g. XSS, prototype pollution, formula injection).
   - Step-by-step instructions or sample CSV payload to reproduce the issue.
   - Any suggested mitigations.

You will receive an acknowledgment of your report within 48 hours.
